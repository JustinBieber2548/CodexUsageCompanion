# Codex Usage Companion 1.0.1

## Changes

- Correctly classifies a seven-day primary allowance as the weekly window.
- Adds a visible **Check for updates** button to the main status window.
- Keeps the user-approved automatic update flow introduced in the Version 1 build.

## Upgrade

Open Codex Usage Companion 1.0.0 and select **Check for updates**. Review the release notes, approve the download and installation, and confirm that the app reopens as Version 1.0.1. Settings, encrypted credentials, notification state, queued synchronization data, and local history remain in the per-user data directory.
